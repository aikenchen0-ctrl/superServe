# 固定时间窗训练切分

日期：2026-11-08。离线可选能力，不改变线上排序、画像写入或旧训练命令默认值。

## 入口

原命令保持：

```powershell
train_ranker.exe catalog.json frozen-samples.json new-model.json
```

显式切分：

```powershell
train_ranker.exe catalog.json frozen-samples.json new-model.json split.json
```

配置结构：

```json
{
  "schema": "rank-temporal-split-v1",
  "train_before": 100,
  "validation_before": 200,
  "embargo_seconds": 5
}
```

以上数字只说明区间，不是生产日期或默认推荐参数。三个时间量均为Unix秒口径。
输入仍是固定目录和`rank-training-v1/v2`，`train_before`在源样本中表示整个快照的排他截止。
源样本最大32MiB、100000条，目录8MiB，配置4KiB，沿用原校验和不可覆盖发布。

## 规则

设训练截止为T1，验证截止为T2，源快照截止为T3，隔离间隔为G：

| 集合 | 曝光时间 | 明确反馈时间 |
| --- | --- | --- |
| 训练 | 小于T1 | 小于T1 |
| 验证 | 大于等于T1+G且小于T2 | 小于T2 |
| 测试 | 大于等于T2+G且小于T3 | 小于T3 |
| 清除 | 落入隔离间隔，或先曝光后跨截止反馈 | 不转移至下一集合 |

全部输入先通过原时间、冻结画像、授权范围、候选、双类与数量校验。
同一`request_id`作为不可分决策：任何一条需要清除，或各条落在不同集合，整组清除。
同一决策不能跨主体复用；`evidence_ref`不能重复。
输入生产者必须提供稳定的真实决策身份，不能把客户端重试键当作决策身份，
也不能通过改写ID把同一决策伪装成多个独立决策。

训练子集重新校验两类反馈；验证或测试为空时拒绝，不自动重采样、移动截止或挑掉冷门领域。
v2同秒曝光/反馈继续要求原来源、交互代次、序号和本地耗时证明，不能只凭同一秒推断先后。
同一用户可以跨窗出现，这是时间留出；审计报告列出验证/测试中见过的用户样本数，
不声称冷启动、主体互斥或匿名用户属于一个共同主体。

训练只使用训练集合；验证、测试保留原输入索引供离线评估消费。
发布模型仍为原`ftrl-ranker-v1`。启用时回执额外包含`temporal_split`：
各窗口总量、分领域数量、清除决策、未知主体和已见主体样本量。
不启用时该字段省略，旧回执和模型训练语义保持。

## 复用

局部迁移RecBole `Dataset.time_based_split`的全局时间边界与掩码机制，
固定提交`7b02be5ec80a88310f2d04a27a82adfcbb5dc211`。
本项目使用事先固定的两个全局截止，增加标签跨窗与整决策清除；
不照搬按样本百分位自动选边界或训练/验证按用户比例切分。
MIT许可与修改范围见`../LICENSES/recbole-NOTICE.txt`。
实际核心和服务端均为Rust，不依赖Python、Pandas、NumPy或PyTorch。

## 证明范围

该切分只能检查已声明的时间和身份关系，不能证明源事件、目录先验或画像在历史时刻真实存在。
来源散列、可信曝光、画像构建、特征计算、候选产生都仍需要各自的时间与来源证据。
输入是合成数据时，输出继续标为合成，不能视为真实效果。

本轮没有在测试窗上选择参数，也没有实现阻止操作者反复查看测试集的权限隔离。
回执明确保留`model_selection_protected=false`和`subject_disjoint_required=false`。
清除会减少样本，可能降低小领域覆盖；报告数量，不能用补造负例掩盖缺口。
未曝光/未反馈仍不自动成为负例，部分标签指标仍不是无偏策略评估。
模型文件本体未绑定原训练来源的密码学证明；原回放中的来源未验证状态不因此改为真。
当前训练发布只训练前窗，不自动评价或批准模型上线。
