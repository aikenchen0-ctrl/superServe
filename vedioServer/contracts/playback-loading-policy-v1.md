# 播放加载策略契约

## 目标

在相同内容、相同观看位置和相同网络条件下，控制当前视频的前向加载行为，减少暂停恢复造成的重复下载，同时在用户继续观看时保持可接受的连续播放。

该契约只约束当前媒体对象，不负责下一条内容预取、推荐排序、用户画像写入或服务端逐分片决策。

## 状态与动作

| 用户状态 | hls.js动作 | 目的 |
| --- | --- | --- |
| 初次启动、加载已停止或跳转后重新加载 | `startLoad` | 建立对应位置的加载流程 |
| 从临时暂停恢复，且原加载流程仍存活 | `resumeBuffering` | 恢复后续分片调度 |
| 临时暂停且可能恢复 | `pauseBuffering` | 停止新分片调度，允许已在途分片完成 |
| 明确停止、划走、切换内容或页面离开 | `stopLoad` 并销毁播放器 | 立即中止在途读取并释放资源 |

`pauseBuffering` 与 `stopLoad` 不能互换。前者保留已经开始的读取，后者会中止在途读取。当前实现仅在原加载流程仍存活时调用 `resumeBuffering`，否则调用 `startLoad`。

## 固定候选

当前实验保留以下候选，禁止在同一批对照中按结果逐次改参数：

- `baseline`：4/6 秒时间参数，512 KiB 字节参数；暂停调用 `stopLoad`。
- `keep_inflight`：4/6 秒时间参数，512 KiB 字节参数；暂停调用 `pauseBuffering`，恢复调用 `resumeBuffering`。
- `small_window`：2/4 秒时间参数，512 KiB 字节参数；暂停调用 `pauseBuffering`，恢复调用 `resumeBuffering`。
- `rust_time`：hls.js仍使用4/6秒及512KiB参数，另用一次取得的策略驱动Rust时间滞回；
  暂停语义同`keep_inflight`，仅在显式配置Wasm资源时可选。

这些参数是 hls.js 的实验参数，不是严格的媒体缓冲上界、进程内存上界或 Media3 策略的逐项等价移植。

## 端侧适配边界

Web 复用固定版本 hls.js 公开接口。Android 和 iOS 必须在各自播放器的公开加载控制接口上实现同样的语义映射，并分别提供：

- 连续可播放缓冲时长；
- 在途请求是否完成或取消；
- 首次可呈现时间；
- 卡顿区间；
- 客户端正文计量范围；
- 停止后的资源回收。

原生播放器没有这些语义时，不得把 Web 的 `pauseBuffering` 名称直接当成已经完成跨端绑定。

## Rust时间控制边界

`vs-core::playback::TimeBufferControl`与完整`LoadControl`共用时间滞回实现，
只输入连续可播放时间和倍速，不拥有网络、媒体字节、起播条件或下载票据。
Web通过`wasm-bindgen`公开外壳运行这一实现；并未绑定`PlayerAdapter`。
完整`LoadControl`的字节准入、在途互斥和起播决定继续保留在原接口中。

浏览器每播放对象校验一次策略目录和内容指纹。策略的其他字段仍会出现在响应中，
但本外壳只应用时间低/高阈值；字节上限与起播参数没有被转换成Rust的执行承诺。
切换内容后旧初始化不得创建新对象，同页Wasm初始化共享一个Promise，
停止、自然结束或致命错误时回收对象与定时器。浏览器边界拒绝NaN、无穷值、负数、非整数及越界输入。
跳转开始时必须先恢复取片，不能等待需要新数据才能产生的`seeked`事件；
定位完成后恢复门控，暂停中的定位则重新暂停后续分片。

新增模块正文、初始化时间、线性内存、策略读取次数和本地判定次数必须单独记录。
比较三低时，不能遗漏模块的冷启动下载，也不能把Wasm线性内存当作RSS。

## 评估门槛

一批有效对照必须固定素材、网络、媒体位置轨迹和重复次数，并同时包含：

- 暂停后继续观看；
- 短看后明确停止；
- 至少一档较快网络和一档受限网络；
- 客户端正文、服务端产出差值、首帧、卡顿、重复片段、取消和许可回收。

评价先分用户行为，再看综合代价。继续观看优先降低卡顿和重复下载；明确停止优先降低停止后的额外接收。不能用不同观看时长的总字节直接比较推荐或编码收益。

## 当前选择

当前保留默认基线，并选取以下机制继续验证：

1. 在显式候选 `keep_inflight` 中，临时暂停使用 `pauseBuffering`，原流程存活时恢复调度。
2. 所有候选在明确划走、停止、切换内容和页面离开时销毁播放器以取消读取。
3. `small_window` 只作为小窗口实验候选，未升级为默认参数。

此前三个非Wasm候选的短看轨迹没有执行暂停，停止逻辑也相同；
其中几KB差异不能归因于暂停策略。Rust候选另有可测量的模块及策略下载，必须加入比较。
当前只是固定播放对象的实验策略，尚未实现对恢复概率的识别或自动策略选择。

该选择来自同机 Chrome、合成素材和模拟网络的有限对照。每个组合仅两次重复，不构成统计显著性、Android、iOS、公网线路、CPU、RSS、功耗或生产 SLO 结论。
