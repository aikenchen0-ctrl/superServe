# 受控私网TURN实验契约

日期：2026-11-08。独立Rust包`vs-turn`，当前仅IPv4/UDP和有限私网/回环范围，
不构成生产公网TURN、集群或无条件扩容方案。

原协议解析、认证、nonce、权限、通道和消息加密摘要全部沿用上游。

## 配置与边界

独立程序通过绝对路径环境变量`VS_TURN_CONFIG`读取至多16KiB配置。
示例见`turn-private-v1.example.json`，到期值0刻意不可直接使用，
必须由受信实验启动器在当次运行生成未来至多300秒的Unix秒数。

受信父进程可显式设置`VS_TURN_STOP_ON_STDIN_EOF=1`并持有独占的标准输入管道。
关闭管道即请求停机，不接受命令数据；收到数据或读取异常仍先回收，再以失败退出码结束。
不设置开关时保持原Ctrl+C或全局到期行为；其他开关值拒绝启动。
该管道不开放网络管理端口，也不能延长授权或迁移分配。
专用读取线程不进入Tokio阻塞池，父管道保持打开也不能阻止全局到期后的进程退出。

标准输出只有两条JSON：`turn-lab-ready-v1`和`turn-lab-stopped-v1`。
两者包含实际PID与绑定地址；前者含期限和管道开关，后者含停机原因与最终统计。
启动器必须匹配实际子进程PID、配置地址及期限，不得仅相信布尔成功标记；
同时并发、有界读取两路输出，检查实际退出码和端口重绑。
父管道不是远程生产治理方案，不以继承其他进程管道的方式共享所有权。

| 对象 | 边界 |
| --- | --- |
| 监听 | 明确IPv4回环或RFC1918地址、非零端口，不接受通配/公网/IPv6 |
| 客户端IP | 1至16个唯一明确IP，最多32个来源IP/端口组合；不动态淘汰 |
| 中继端口 | 1至8个唯一、至少1024的实际系统UDP端口，不是虚拟端口 |
| SFU目的地 | 1至8个完整IP/端口，禁止本监听及中继端口自环 |
| 凭据 | 1至8个唯一用户、32至128字节密码，实验生成随机值 |
| 控制请求 | 每来源端点整个实验至多512个请求，非每秒速率 |
| 内存与I/O | 4KiB入站上限，32条队列，单轮动作和输出各256预算，发送100ms期限 |
| 生命周期 | 启动单调期限和不回退墙钟任一到期即停止转发并回收 |

客户端来源IP准入不能替代TURN协议认证；真实中继分配仍要求上游认证成功。
CreatePermission按协议使用IP，但本项目在入站前限定允许IP及属性数量，
ChannelBind与实际收发限定完整SFU端点，不能借同IP权限访问不同端口。
不允许靠输出丢弃掩盖入站无界权限增长。控制请求预算、来源名册和短寿命仍是实验代偿，
不是生产防滥用、无损长期服务或弹性伸缩证明。

分配释放先停止并回收读取任务，再允许重用端口。
每个读取任务附有不可复用代次，旧队列数据即使目的端口相同也不能进入新分配。
这只隔离进程内部队列；网络上到达的新数据仍由实际TURN权限和后续DTLS/SRTP裁决，
不能据此宣称跨进程旧数据或全网乱序完全消失。

读写字节统计均是应用UDP负载，不含IP/UDP头、链路重传、TLS信令或操作系统开销，
不是线路账单。额外中继会增加转发和带宽，当前没有总体三低收益结论。
底层采用上游按协议所需的SHA1/MD5/HMAC机制，不把这些摘要当用户密码存储方案；
长随机实验凭据与短寿命不能替代生产凭据签发、撤销和轮换。

## 客户端接线

现有Web实验页面可由可信初始化传入`window.liveRtcConfiguration`，
当前只支持至多4个服务器、每个至多4个`turn:...?...transport=udp`地址及固定凭据。
`iceTransportPolicy`为`all`或`relay`；默认仍是空服务器的`all`。
客户端配置不能通过URL参数、用户输入或不可信媒体结果自动注入。
它不创建生产凭据发行者；Android/iOS仍需原生WebRTC适配，不以WebView为前提。

同日后续`run-signaling-browser.ps1 -Relay`改用[受保护ICE发现](live-ice-discovery-v1.md)，
夹具不再注入TURN密码，浏览器在首次ICE收集前从HTTPS取得配置。
此能力不修改TURN共享密码的授权寿命，JWT撤权不等于撤销已交付密码。
该脚本复用HTTPS/JWT实验，强制检查每条连接选中`relay`候选，
实际分配端口、H264/Opus解码、画面/音频变化和最终回收。
浏览器模式通过绝对路径`VS_TEST_TURN_BINARY`启动独立`vs-turn.exe`；
配置在当次临时目录中交付，不把密码放命令行或结构化回执。
验收就绪/停机PID、双向字节、父管道关闭原因、实际退出码0及最终分配0，
并重绑监听与全部中继端口；两路输出各最多8KiB，就绪/退出各最多等待5秒。
当前已验证同机独立TURN进程的真实浏览器媒体，不是独立物理机器或吞吐基准。
直连默认和内部mTLS控制链必须另验，不能用强制relay通过替代。
