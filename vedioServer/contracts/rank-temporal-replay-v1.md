# 固定训练来源的留出回放

日期：2026-11-09。离线可选能力，不改线上推荐、旧训练命令和旧证据回放。

## 输入

```powershell
replay_temporal_holdout.exe catalog.json replay-config.json new-report.json
```

```json
{
  "schema": "rank-temporal-replay-v1",
  "source": {"path": "source.json", "sha256": "替换为冻结样本SHA256"},
  "split": {"path": "split.json", "sha256": "替换为固定切分配置SHA256"},
  "model": {"path": "model.json", "sha256": "替换为模型SHA256"},
  "window": "validation",
  "domain_audit": {
    "required_domains": ["video", "article", "service"],
    "minimum_positive_labels": 1,
    "maximum_positive_coverage_drop_basis_points": 0
  }
}
```

摘要占位不能直接执行。来源为冻结的`rank-training-v1/v2`，
切分为`rank-temporal-split-v1`，模型为`ftrl-ranker-v1`。
路径只接受配置目录内普通相对路径，解析后不得逃逸；共享文件锁和SHA256复用原`read_pinned`。
目录本身摘要须匹配来源与模型。`window`只允许`validation`或`test`，
一次只评价一个窗口，不自动选优。可省略`domain_audit`，但省略不代表已通过领域门槛。

## 执行边界

1. 完整校验输入，执行固定时间切分及整决策跨窗清除。
2. 用前窗和当前确定性FTRL重现模型；重现产物也经原JSON发布/读取链，
   与输入模型的完整类型化内容严格比较，不只相信`trained_before`。
3. 按所选后窗的稳定服务端决策ID归组，同决策请求与画像时点必须相同。
4. 在同一历史请求下执行完整目录标签基线和固定模型排序，不仅重排已反馈候选，
   不按领域各补一个Top-K再拼接。
5. 复用原Recall/NDCG/MRR和逐领域明确反馈审计；零命中、负例和未知均保留。

评价时点为该决策最早的、有明确反馈的曝光时点，不冒充决策签发时点。
历史画像须在该时点有效，过滤和权限仍由`RequestContext`决定。
训练样本格式没有零反馈或未显示决策，不能推造这些事实；
完整决策成本分析继续使用原`replay_model_evidence`，两条入口不互相替代。

固定JSON默认浮点读取可能与训练内存值存在末位差异。
两端均经过相同模型读取链后严格比较；未修改全局解析特性、在线权重或比较容忍度。
该核验表示当前实现可重现实际加载模型，不是历史来源或训练过程的密码学证明。
模型重现额外执行一次有界离线训练，不能称为零成本血缘检查。

## 输出

报告包含目录、来源、切分、模型、训练窗和配置摘要，
逐决策保留散列引用、时点、领域、候选ID及部分标签指标，不输出原主体或完整画像。
散列引用不等于匿名化，报告仍须按派生用户数据治理。
无正标签时相关指标为`null`；宏平均仅以有正标签决策为分母，零命中仍参与，
负例决策单独计数。这不是全用户平均质量。

| 退出码 | 含义 | 报告 |
| --- | --- | --- |
| 0 | 输入核验及可选诊断门槛通过 | 不可覆盖发布 |
| 2 | 输入有效，但逐领域门槛未通过 | 仍保存诊断报告 |
| 1 | 输入无效、模型无法重现、预算超限或发布失败 | 不发布新报告，不覆盖原文件 |

预算：目录8MiB、回放配置256KiB、切分配置4KiB、模型128KiB；
来源及其他固定文件合计32MiB，来源样本最多100000条。
每窗最多1000决策、两条排序最多五千万目录逻辑评分单位，报告16MiB。
评分单位不含训练重现、源校验、序列化或真实CPU/RSS，不用于性能排名。

## 复用与限制

沿用固定RecBole时间机制、固定Recommenders命中分母/逐查询汇总参考、
既有Rust指标和领域审计及Qdrant来源的不可覆盖发布适配。
许可见`../LICENSES/recbole-NOTICE.txt`、`../LICENSES/recommenders-MIT.txt`及`../THIRD_PARTY.md`。
不复制Python运行时、pandas或按共同预测用户丢弃样本的路径，无新增依赖。

报告始终标记：部分标签诊断、历史来源真实性未验证、无偏策略评价未完成、
模型选择未隔离、主体不要求互斥、生产门槛未通过、线上策略未改变。
合成保持合成，同用户跨时间窗并非冷启动。
反复查看测试窗、重新选截止、未来目录先验等风险仍需独立约束；
全部诊断通过也不证明真实推荐提升或总体三低。
