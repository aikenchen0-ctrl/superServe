# 原始反馈证据快照

`feedback-evidence-v1`用于可信离线工作目录，保留Iggy固定区间内的原始消息，
避免学习投影丢失首帧、进度、卡顿、字节声明及没有明确偏好的消费记录。
它不是公共指标接口，不自动证明用户真实观看、日志历史真实性或生产准入。

## 入口

```text
snapshot_feedback <配置JSON> <起始偏移> <排他结束偏移> <新归档JSON> --raw-evidence
```

省略选项继续生成原来的`gateway-learning-events-v1/v2`学习投影，
原回执格式不变。新增选项生成一个不可覆盖文件和
`iggy-feedback-evidence-snapshot-v1`摘要回执；回执不输出主体、原始批次或凭据。

归档字段：

| 字段 | 含义 |
| --- | --- |
| `schema` | 固定`feedback-evidence-v1` |
| `source_id`、`data_kind` | 固定来源及合成/观测分类 |
| `stream_id`、`topic_id`、`partition_id` | 已配置消息坐标，不支持一份文件拼接多个分区 |
| `start_offset`、`end_offset_exclusive` | 非空的固定排他区间 |
| `captured_at` | 开始读取时的服务端UTC秒，用于重新验证事件上界，不是消息提交时刻 |
| `messages` | 原顺序完整消息列表，重复提交不按载荷去重 |
| `messages[].offset` | 连续消息偏移 |
| `messages[].message_id` | SHA256前16字节的大端无符号整数，以十进制字符串保存，避免JavaScript精度损失 |
| `messages[].payload_length` | 解码后原始字节长度 |
| `messages[].payload_sha256` | 原始字节SHA256 |
| `messages[].payload_base64` | 标准Base64，保留原始JSON字节，不用重新序列化的对象代替 |

## 读取与发布边界

- 复用固定Apache Iggy HTTP读取机制，不复制消息服务器或新建消费框架。
- `auto_commit=false`、显式偏移，每页最多8条，整份1至128条消息。
- 每批最多32KiB；每页响应最多512KiB；新归档最多8MiB。
- 多入口先按既有就绪校验选定一个地址，分页期间不跨入口拼接。
- 原始载荷通过原消费/学习校验链；仅QoE消费允许空学习投影，旧协议空批次仍拒绝。
- 开始读取时冻结事件时钟上界；未来事件不能因分页耗时而转成可接受。
- 读完并验证后才执行既有原子不可覆盖发布。许可持有到发布结束，最多4个并发任务。
- 无写入重试、消费位点变更、新网络端点、新外部依赖或线上默认变化。

`learning_projection()`重新检查版本、范围、连续偏移、大小、编码、摘要、消息标识及批次语义，
再调用原消费归一化逻辑。训练证据导出和旧模型回放可直接使用新文件：
原`EvidenceExportManifest.gateway_events`的相对路径和SHA256约束仍适用。
同一载荷不因重复偏移而丢弃；学习事件去重和冲突规则仍由原导出层决定。
未知不是负例；没有标签的记录留在原始证据中，不强行生成训练样本。

## 尚未证明

文件内校验和摘要只能证明内部关系，不能阻止有权限者整体重造文件并重算摘要。
坐标不是可信签名，当前文件不包含可独立验证的broker实例或主题创建代次证明。
单入口快照仍沿用既有读取策略，不宣称读取期间主题重建或跨物理副本一致性已解决。

原始证据含主体、决策和交互标识。Base64不是匿名化或加密，必须受访问、保留期、
授权撤回和删除策略管理；本轮没有补齐这些生产治理机制。
客户端字节声明不是线路计费，首帧声明不是采集到屏幕延迟，累计计数不能直接跨批相加。
批内验证不是完整跨批去重、代次重建、QoE汇总或三低联合基准。
还没有真实Android/iOS设备、公网、真实用户数据、物理集群和生产容量证据。
