This project adapts only the monotonic integer cumulative-to-delta mechanism:
retain the first observed point as a baseline (InitialValueDrop), then subtract
the previous value for later observations in the same metric identity.

Local changes:
- Rust u64 and Option fields instead of Collector pdata and concurrent state.
- Explicit sequence and elapsed-time window metadata.
- Counter decreases fail validation instead of automatically rebasing.
- Duration deltas cannot exceed their observed elapsed-time interval.
- Unknown values are not filled with zero or interpolated.
- No histograms, exporters, collectors, state expiry or background workers.

The upstream root NOTICE only describes processscraper/gopsutil and grpcutil
portions, neither of which is copied or used by this adaptation.
