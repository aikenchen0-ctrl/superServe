# 反馈入口切换与未知写入边界

日期：2026-11-07，香港时间。范围：既有 Iggy HTTP 适配，不修改日志内核。
状态：实现、52项定向回归、独立进程及静态检查通过；真实集群准入仍未完成。

<重表述提示词为问题>如何在反馈日志入口失联后恢复后续消费与偏好采集，同时避免把结果未知的写入重新发送，并限制探测、连接和跨入口读取的新增代价？</重表述提示词为问题>

## HMM 问题与取舍

现状 S0：三端共用消费协议，Iggy 适配只有一个地址；此前真实三节点实验需要手选幸存入口。
理想需求 IFR：入口失联不要求用户干预，已提交事实不被重复记录，采集不增加播放与推荐热路径的等待。
现实目标 Sg：运维配置固定地址，由启动检查或外部就绪探测选择有效入口；后续写入使用该地址。

用户需要少量上传、稳定播放和正确偏好；运营方承担连接、日志与探测成本；
维护者需要明确区分未提交、已确认和未知。真实用户身份仍由尚未接入的网关负责。

技术矛盾 TC：自动重发可能改善表面可用性，却可能重复已经提交的反馈。
核心矛盾 PC：同一结果未知的写入，为恢复采集需要再次发送，为避免重复又不能再次发送。
采用时间分离：本次请求保留 unknown，只读检查选择下一入口，切换只作用于后续请求。
已有调用方取消守卫和四个在途许可继续保留。

本轮三个待办问题：

1. 固定入口选择、写入边界、独立进程与回放回归：本轮深入。
2. 用户网关、Android/iOS/Web 原生采集、授权撤回与真实跨域效用：继续开放。
3. Iggy 本地文件系统退出、保留、物理故障域及实际扩容：继续开放。

没有用新增集群或分布式路由框架替代这三个不同问题。

## 配置与执行

旧配置省略 `fallback_endpoints` 时仍可读取，序列化空列表时省略该字段。
非空列表要求先升级收集进程与快照工具；旧二进制严格解析配置，会拒绝新字段。

```json
{
  "endpoint": "https://broker-a.example",
  "fallback_endpoints": [
    "https://broker-b.example",
    "https://broker-c.example"
  ],
  "stream_id": 0,
  "topic_id": 0,
  "partition_id": 0,
  "source_id": "trusted-gateway",
  "data_kind": "synthetic",
  "operation_timeout_ms": 1000
}
```

最多四个固定根地址，规范化后不能重复，必须使用相同协议。
拒绝地址内凭证、路径、查询和片段，不追随重定向或上游公布的动态地址。
这些地址必须由运维确认属于同一可信日志资源，Bearer 凭证会发送给所配置的探测目标。
示例不是生产身份或观察数据配置。

启动已有 `verify_feedback_readiness()`，运行中由受保护的 `/readyz` 调用同一逻辑：

1. 优先上次通过验证的入口，之后按配置顺序检查其他地址。
2. 只读探测共用一个 `operation_timeout_ms` 总期限，各候选分配剩余预算。
3. 只有连接失败或收到响应头前超时才尝试下一地址。
4. HTTP 拒绝、重定向、正文损坏/超限、非显式 persisted、分区错误均立即失败。
5. 完整校验后才选中入口；就绪检查失败清空选中状态，后续写入等待重新通过检查。

多地址配置在首次就绪检查前不发送 POST。
第一次成功检查在进程内固定主题和分区创建时间；后续检查不接受重建资源。
这两个时间字段只是上游资源声明的一致性约束，不是加密身份、集群成员证明或历史内容证明。
进程重启后重新建立该约束，仍依赖运维可信配置；没有新增持久化路由状态。

后续 POST 沿用原协议，只向当前已选地址发送一次。
连接失败、超时、错误状态、缺失持久化声明或确认坐标不符均为 unknown。
本次写入不会调用就绪探测，不会尝试备用地址，也不在后台补发。
因此主机刚失联时仍可能有一次或多次未知结果，恢复时延受外部就绪探测频率影响。
没有内部定时器，也没有宣称无损或即时自动故障转移。

多地址快照在读取前进行一次完整就绪检查，全部分页固定同一入口；
中途失败则整份归档不发布，不跨入口拼接页，不推进消费位点。
新字段 `topic_readiness.endpoint_index`、`feedback.endpoint_count`、
`feedback.active_endpoint_index` 用于观测；尚未选中时活动索引为 null，不输出地址或密钥。

## 三低代价

正常写入没有新增逐批 RPC、会话表、后台工作线程或持久化路由文件。
切换增加只读元数据请求，连接池最多涉及四个主机，可能增加闲置连接与 TLS 握手成本。
多地址快照新增一次元数据核验；固定单入口意味着大快照中途失联仍需整体重新开始。
均分候选预算可能在高延迟环境产生额外就绪失败，参数仍需真实网络轨迹确定。
没有 CPU、RSS、线路字节、播放延迟或生产吞吐收益结论。
