## HMM 与候选

`S0`：本地完整发布和固定目录版本已接通，远端分段上传仍缺少可调用的生命周期边界。
`IFR`：流式处理而非整文件驻留；相同内容不覆盖；取消后有界清理，失败不破坏最终对象。
`PC`：请求希望及时停止，创建和提交结果又必须返回才能获得上传ID或确认是否提交。
按时间分离：当前存储操作结束或超时后处理取消，清理任务独立于等待者；提交开始后不按取消删除目标。

用户需要媒体精确与重复请求可恢复，运营方承担远端暂存、重试和故障处理成本。
硬边界是分布式响应可丢失：没有收到上传ID或完成响应，不代表服务器没有执行。

## 实现边界

新增`S3Publisher`和独立CLI，复用OpenDAL Writer：

```text
接纳预算
-> 检查已有对象
-> 按64KiB读取源，计算长度/SHA256
-> 受限分段，单段并发，if_not_exists
-> 验证源完整性
-> 最终条件提交
-> 成功收据，或带清理/提交状态的错误
```

现有对象必须完整读回核对散列和长度才可复用，不只凭HEAD或ETag。
新建收据的`source_verified`表示提交给SDK的源已核对，不能当独立远端读回证明；
`existing_object_readback_verified`明确区分重试复用的完整读回。
并发失败方收到412后先中止自己的分段，再验证赢家；不覆盖任何赢家。

409冲突不重试同一次close；调用方需重新发起整个上传。
HTTP 200内嵌错误交给锁定SDK解析，测试证明不会当作成功。
未成功校验的源在close前中止，不把坏内容变成已发布对象。

默认5MiB分段、两个上传、每上传单段并发、30秒单操作上限和10秒清理上限。
可配置范围为5至32MiB分段、1至16上传、100毫秒至120秒单操作、100毫秒至30秒清理。
超过10000个分段的资产拒绝接纳；调用方需选更大分段。
SDK缓存、在途分段和读取缓冲另占内存，不把“分段大小×上传数”当作整个进程RSS上限。

没有增加包版本；OpenDAL与HTTP传输器改为service直接运行依赖，quick-xml解析协议夹具，
Tokio显式声明fs/io-util。锁文件因直接依赖关系变化，字节指纹已更新。
没有复制签名或分段内核，也未把上传挂到互联网HTTP接口。

## 取消和不确定性

`start_file`返回受监督句柄；显式取消、丢弃句柄或丢弃等待Future只发取消信号。
后台工作任务继续持有接纳许可，完成有界清理后才释放。
`shutdown`用于排空并关闭接纳；运行时被强制结束或进程崩溃仍无法保证执行清理。

取消不是立即中断每个请求：先让当前有界写操作返回，再检查信号。
这避免主动丢掉刚返回的上传ID，但取消可能等待操作预算，之后还要等待清理预算。
上传一旦进入最终提交，取消不会删除目标；提交成功仍记成功，响应丢失记不确定。

结果分为：

| 状态 | 含义 |
| --- | --- |
| `not_required` | 本轮无需分段中止，例如成功提交或直接复用已有对象 |
| `abort_acknowledged` | SDK中止调用成功；不等于证明所有远端工作或暂存已经消失 |
| `unconfirmed` | 中止失败/超时，或写操作结果丢失导致不能证明已有正确上传ID |
| `commit_may_have_succeeded` | 本次提交可能已成功；禁止据错误删除最终对象 |

保留的确定性协议反例：

1. 创建上传的响应被阻塞直到超时，服务器已有一个暂存上传，客户端没有ID可中止。
   本地任务排空，但结果为`unconfirmed`，不把释放许可写成远端无残留。
2. 服务器已完成提交但响应丢失，客户端超时仍保留最终对象，结果标为可能成功；
   重试完整读回后复用，不重复覆盖。
3. 服务器拒绝Abort时，取消结果保持`unconfirmed`，上传暂存仍在。

因此生产存储仍需要过期未完成分段的生命周期规则、对象核对和运维补偿。
本轮没有自动配置生产规则，没有列举或清理任何非实验桶。
状态计数是观测，不能代替远端事实；异常退出后的未知上传ID尚未自动恢复。

## 使用与复现

普通上传CLI使用既有`VS_S3_ENDPOINT`、`VS_S3_REGION`、`VS_S3_BUCKET`、
`VS_S3_ACCESS_KEY_ID`、`VS_S3_SECRET_ACCESS_KEY`环境配置；上传和媒体只读凭证分开提供。

```powershell
cargo build --locked --manifest-path vedioServer/Cargo.toml -p vs-service `
  --example publish_s3_media --example s3_publication_contract
./vedioServer/target/debug/examples/publish_s3_media.exe `
  <源文件> <SHA256> <字节数> <内容类型>
```
