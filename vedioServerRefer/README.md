## 范围冻结

当前职责不是单一的短视频推荐，而是以下两个数据面共同组成的系统：

- 媒体数据面：上传、转码、存储、分片、缓存、分发和播放反馈。
- 画像推荐数据面：跨场景用户画像、知识图谱投影、多路召回、排序、列表生成和反馈更新。

两套数据面以 Rust 服务和最小接口连接；分布式元数据、事件流、对象存储的共享范围仍需验证。
原始个人资料与推荐特征之间必须有明确的授权和投影边界。早期选型文件是候选档案，当前决定以
`根参考与开发计划.md` 和实际代码、测试为准。

## 已确认约束

- 第一方在线服务统一使用 Rust。
- 训练与原生内核路线尚待评估；用户未明确批准 Python 作为生产依赖。
- 服务必须支持分布式、多机集群和运行时扩容。
- 视频算法、视频存储、推荐算法和画像治理都在选型范围内。
- 目标优先级为低性能开销、低带宽开销和用户体感低延迟。
